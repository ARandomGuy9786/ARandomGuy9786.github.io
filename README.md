# arandomguy9786.github.io

Portfolio of Min Htet Aung (Nicholas): AI & security engineer, Bangkok.

Next.js static export, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
```

- Pages: `app/page.tsx` (home), `app/work/ammunity/`, `app/work/bank-monitor/`
- Skills & certifications: `lib/content.ts`
- Scroll story: `components/HomeMotion.tsx` (GSAP ScrollTrigger; off under reduced motion)
- The CV download is `public/Min-Htet-Aung-CV.pdf`, the web copy without a phone number.

Illustrations are original, inspired by comic art.
